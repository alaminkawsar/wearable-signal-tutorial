## The one-paragraph big picture

You have `n` vectors in `d` dimensions (e.g. 96 embeddings × 512-D). Humans can only look at 2-D,
so you *project* (PCA: a linear, reversible-on-the-subspace, deterministic map that keeps global
distances roughly true) or you *embed* (t-SNE: an optimised, non-linear layout that keeps only
*neighbourhoods* true). Once plotted, your eyes lie to you — t-SNE invents clusters, PCA flattens
real ones — so you confirm what you see with *numbers computed in the original space*: a
similarity/distance choice (cosine or L2 — the same thing if vectors are L2-normalised, very
different if not), similarity heatmaps (clusters become blocks), and silhouette scores /
centroid-gap-vs-spread comparisons (is the between-group distance actually bigger than the
within-group noise?).

```
 raw vectors (n × 512)
        │
        ├── PCA  ──────────► 2-D scatter   (axes = variance, distances comparable,
        │                                    projection of a mean is EXACT)
        ├── t-SNE ─────────► 2-D scatter   (neighbourhoods only; NO new points,
        │                                    cluster size/distance mean nothing)
        ├── cosine / L2 ───► heatmap       (blocks = clusters; read diagonal structure)
        └── silhouette ────► one number    (+ centroid gap vs within-group radius)
```

## Quick decision guide

| Situation | Use |
|---|---|
| "Show me where my summary/mean vectors sit among the single samples" | **PCA** — the mean's projection is exact |
| "Is there *any* cluster structure, exploratory" | **t-SNE** (and check it with a silhouette number) |
| Learned embedding vectors whose norms vary a lot | **cosine** similarity |
| Vectors already L2-normalised | cosine and L2 are interchangeable (`L2² = 2(1 − cos)`) |
| "How confident am I in these two groups?" | **silhouette** + centroid gap / within-group radius |
| n < ~50 samples | PCA + heatmap; t-SNE and silhouette become unreliable |

## Worked running example (this repo)

The notebook
`cgm/glucose-estimation/experiment-notebook/premeal_postmeal_ppg_embedding_vis_meal_related.ipynb`
uses exactly these four tools on pre-meal vs post-meal PPG embeddings (96 chunks × 512-D,
11 mean-pooled file vectors). Its results are a *negative* control worth learning from: PCA/t-SNE
show overlapping clouds, the heatmap shows no block structure, silhouette ≈ 0 and
within-group cosine ≈ between-group cosine — the textbook signature of "no cluster structure yet".
Each tutorial doc ends with the exact code line from that notebook that corresponds to the concept.
